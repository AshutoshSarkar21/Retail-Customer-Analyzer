1. Project Overview

Retail Customer Analyzer is a menu-driven Python application that analyzes customer spending data stored in a CSV file. It uses the Pandas library to calculate spending statistics, identify high-value customers, and generate city-wise spending summaries.

2. Project Objectives

- Analyze customer spending data.
- Calculate mean and median spending.
- Identify the highest and lowest spenders.
- Filter customers based on a spending limit.
- Generate city-wise total and average spending.
- Handle invalid user inputs and missing data files.

3. Features

1. Spending statistics.
2. High-value customer filtering.
3. City-wise spending summary.
4. Input validation.
5. CSV file handling.

4. Technologies Used

- Python 3
- Pandas
- CSV file handling
- Visual Studio Code

6. Requirements

Install Python 3 and Pandas.

Install Pandas using:

pip install pandas

7. How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Ensure "one.py" and "customers.csv" are in the same folder.
4. Open the terminal.
5. Run:

python one.py

6. Select an option from the displayed menu.

8. Sample Dataset

The CSV file contains these columns:

- CustomerID
- Name
- City
- Purchases
- TotalSpent

9. Test Cases

The project was tested using the four prescribed test cases:

- Test Case 1: Normal spending statistics.
- Test Case 2: High-value customers with a limit of Rs. 25,000.

- Test Case 4: City-wise total and average spending.
